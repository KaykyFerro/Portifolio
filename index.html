FinanceFlow

Sistema de gestão financeira pessoal desenvolvido para centralizar receitas, despesas, contas, investimentos e análises em uma única aplicação. A proposta reúne dashboard, transações com filtros e edição, relatórios por período, separação entre patrimônio e investimentos e tema claro/escuro.

Temporariamente indisponível para demonstração: o banco de dados sofreu uma falha, por isso o site está desativado e não há capturas de tela atuais. A descrição documenta o projeto desenvolvido, não o estado operacional presente.

Arquitetura planejada e desenvolvida com C#/.NET 10, ASP.NET Core Web API, Entity Framework Core, PostgreSQL, Docker e automações do GitHub Actions para gerar uma versão Android baseada em WebView.

APLICATIVO WINDOWS

ScreenFlow ↗

Aplicativo desktop para compartilhar tela, câmera e áudio do computador em tempo real pela rede virtual do Radmin VPN. Permite transmitir em até 4K a 165 FPS, conectar múltiplos espectadores, acompanhar latência, perda de pacotes e banda, além de oferecer chat e comunicação por voz entre pessoas na mesma rede.

Construído para Windows com C# e WPF, o projeto utiliza captura acelerada por GPU, codificação de vídeo por hardware (NVENC, AMF ou Quick Sync), áudio via WASAPI e transporte UDP com criptografia, FEC e retransmissão seletiva. Também inclui descoberta de transmissões, reconexão automática, gerenciamento de sessões, atualizações integradas e instalador próprio.
